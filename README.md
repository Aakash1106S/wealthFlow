## ✨ Overview

**WealthFlow** is a modern and intelligent Personal Expense Tracker designed to help users monitor spending habits, manage finances efficiently, and gain meaningful financial insights through beautiful analytics and visual dashboards.

> Whether you're tracking daily expenses, analyzing monthly spending, or planning savings goals, WealthFlow makes personal finance management simple, elegant, and efficient.

The application provides a seamless and responsive user experience with secure authentication, categorized expense tracking, interactive charts, and real-time financial summaries — all wrapped inside a clean and professional dark-themed interface.

## 🚀 Key Features

| Feature | Description |
| :--- | :--- |
| **🔐 Secure User Auth** | Protected routes & JWT-based authentication. |
| **📊 Interactive Analytics** | Pie charts & data visualization for expenses. |
| **💰 Real-Time Balance** | Instant updates to your overall financial standing. |
| **🧾 Categorized Tracking** | Easily group your spending to see where your money goes. |
| **📈 Expense Insights** | Weekly & monthly trend analysis and savings rate monitoring. |
| **⚡ Modern & Smooth** | Fully responsive dark theme UI with Framer Motion animations. |
